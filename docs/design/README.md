# FocusFlow design ground truth

This folder vendors the binding frontend design contract from the OpenDesign
project `focusflow-redesign` (approved 2026-11-07, refined 2026-11-08) so the
source of truth lives with the code.

The generated clickable prototype is a local reference only. OpenDesign writes
it to `prototype/`, which is ignored by Git; the contract files are committed.

## Binding files

| File | Role |
|---|---|
| `DESIGN.md` | Binding design system: direction, colour, type, spacing, component rules, semantic state table, motion, voice, anti-patterns |
| `tokens.css` | All design tokens in `:root` and `.dark`, plus the Tailwind v4 `@theme inline` bridge |
| `implementation-handoff.md` | Binding constraints for the React build: colour, type, shape, spacing, motion, rail props, responsive rules |
| `PROTOTYPE-NOTES.md` | Screen map, how to reach every prototype state, mock behaviour, and deviations |

## Local prototype (ignored)

The prototype is generated by OpenDesign and lives in `prototype/` on the
machine that produced it. It is intentionally not committed.

| Local file | Role |
|---|---|
| `prototype/index.html` | The full clickable prototype (entry) |
| `prototype/app.css` | Prototype component and screen styles, built on `tokens.css` |
| `prototype/js/` | Prototype utilities, mock data, planner, views, routing, and interactions |
| `prototype/today-board.html` | The approved two-theme Today board, kept as the visual baseline |

## Viewing the prototype

If you have the OpenDesign project or a local copy, open `prototype/index.html`
in a browser. The prototype has no build step, but it loads Newsreader, Inter,
and JetBrains Mono from Google Fonts; offline it falls back to system fonts.

The prototype is a design reference:

- Its data is mocked in `prototype/js/core.js`.
- Its routes are hash routes (`#/today`, `#/tasks`, …). Production routes are
  defined in the frontend redesign spec.
- Its "Demo" control is a prototype-only state switcher and must not ship.
- Its native HTML form and dialog primitives are illustrative. The production
  build uses React, Tailwind v4, and shadcn/ui on base-ui, and the custom
  date/time controls described in the spec.

## What is binding

`DESIGN.md`, `tokens.css`, and `implementation-handoff.md` are the binding
visual contract. The prototype demonstrates them; it does not override them.
If the prototype and the contract disagree, the contract wins.
