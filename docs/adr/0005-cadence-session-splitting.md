# Use an optional target cadence with look-ahead

A focus cadence only matters if a task longer than one target stretch becomes several sessions with rest between them. Cadence is explicitly enabled or disabled; zero is not a magic off value. When enabled, the scheduler uses look-ahead around `targetFocusMinutes`: a final tail shorter than `minSessionMinutes` is absorbed before the break, allowing an overrun of at most `minSessionMinutes - 1`, and an early break occurs before a new task when the remaining focus budget is too short for a minimum session. Cadence and fixed breaks reset accumulated focus; commitments pause placement but do not count as rest. Never splitting would permit unbroken multi-hour work, while a hard maximum would create tiny tails and contradict the chosen minimum-session invariant.
