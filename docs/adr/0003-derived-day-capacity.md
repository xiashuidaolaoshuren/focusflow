# Schedule time is derived, not typed in

Scheduling inputs contain a planning date, not a typed minute budget. Stage 1 derives `freeMinutes` from the work window minus fixed breaks, overlapping commitments, and trailing buffer; stage 2 derives `scheduledWorkMinutes` after cadence breaks and task boundaries. Calling the first value “capacity” was rejected because a 50/10 cadence cannot schedule 540 work minutes inside nine free hours. Plan history reports scheduled work minutes, work sessions, distinct source tasks, and unplaced work rather than counting every rest block as an item. A fully unavailable day is still a valid ranked plan whose work is all unplaced. Obsolete `availableMinutes` is ignored under the existing unknown-property policy. Optional per-day window overrides were rejected: change preferences, or accept the saved window.
