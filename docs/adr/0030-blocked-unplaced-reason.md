# Unfinished blockers leave the dependent unplaced as BLOCKED

A ranked task whose active blocker in the same ranking is not fully placed gets no work sessions and one `BLOCKED` unplaced row. Known remaining effort is unplaced in full. Unknown remaining effort is `BLOCKED` with null minutes, which takes precedence over `NO_ESTIMATE`. A blocker that itself has no estimate is not fully placed, so its dependents do not fill the time it skipped.

Relying on ranking order alone was rejected because the placer skips an unestimated task without moving the clock, which would schedule the dependent in the blocker's place. Partial placement of a blocked task was rejected because a gap before the unfinished blocker is not available to the work that must follow it. Folding blocked minutes into the out-of-time warning was rejected because the day did not run out of time; the shortfall warning lists must-include blocked tasks on their own while `requiredMinutes` still counts them. Optional blocked work keeps its own unplaced explanation and does not raise that warning. Fully placing a blocker is planned completion: it allows the dependent to be scheduled later in that plan and does not mark the blocker Done.
