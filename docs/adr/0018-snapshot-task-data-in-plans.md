# Snapshot ranked tasks separately from plan blocks

Each ranked candidate becomes one `DailyPlanTask` snapshot holding rank, immutable `sourceTaskId`, title, priority, status, due date, estimate-at-generation, must-include classification, unplaced reason/remainder, and a nullable `taskReferenceId` foreign key with `ON DELETE SET NULL`. `DailyPlanBlock` holds only clock intervals and work blocks reference that snapshot. Session grouping and warnings use the immutable source id; the live reference only enables navigation while the Task exists. Description is deliberately excluded so free-form notes are not retained indefinitely. Keeping only a live Task would make edits rewrite history and deletion fail, while duplicating snapshots per session would make a single task's state non-atomic and complicate 1.3.0 actuals.
